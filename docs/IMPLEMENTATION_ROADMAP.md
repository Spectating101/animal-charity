# Implementation roadmap

## Stage 0 — synthetic invariants

Current branch.

- policy context cannot fabricate animal cases;
- acute welfare preempts optimization;
- lost owned animals route toward reunification;
- preventable owner surrender routes toward retention support;
- reproductive free-roaming animals create source-control paths;
- ecology-sensitive sites block automatic community return;
- foster/adoption is distinct from source control;
- specialist role is referral-only;
- repeated transition failures create structural signals.

## Stage 1 — retrospective public/partner replay

Use historical cases from one cooperating organization/area.

Questions:

- Could the router reconstruct the intervention actually chosen?
- Did it identify a smaller/earlier intervention?
- Where was necessary evidence missing?
- How often would it have produced a false or unsafe route?

No live decision changes.

## Stage 2 — shadow-mode regional triage

Run alongside existing operations in a bounded official/partner landscape.

- ingest condition observations;
- issue proposed routes;
- compare with human decisions;
- track disagreements and outcomes;
- never act autonomously.

## Stage 3 — assisted case coordination

Allow low-risk coordination after named human approval:

- owner-contact tasks;
- appointment/transport coordination;
- foster-capacity requests;
- food/logistics actuator;
- evidence requests;
- reminders/escalation.

Medical, ownership, sterilization, placement, return and irreversible decisions remain external human authority.

## Stage 4 — structural initiative experiment

Once repeated transition failures are independently established:

- compare extending an existing service vs reversible new initiative;
- run time-bounded pilot;
- measure population/transition outcomes;
- stop if the initiative adds burden without reducing the underlying failure.

Examples: targeted sterilization/registration outreach, foster-recruitment network, owner-retention support, transport route, food-support point.

## Stage 5 — specialist referral integration

Only after the basic welfare system works.

Partner with qualified organizations; the control plane may surface candidates with longitudinal positive evidence but cannot accept/certify them. Track both human benefit and animal welfare during training/service.

## External success bar

The project becomes socially credible only when an external partner can show that the control layer changed a real trajectory for the better, for example:

- a safe owned animal avoided unnecessary surrender;
- a lost animal was reunited faster;
- unmanaged reproductive recruitment fell in a target landscape;
- foster capacity prevented shelter overstay;
- a recurring welfare gap disappeared after a structural initiative;
- a specialist referral succeeded without compromising the animal's welfare.
